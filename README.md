# PROYECTO ACADÉMICO: AUTOMATIZACIÓN CON BASH

## . Descripción del proyecto

Este proyecto consiste en el desarrollo de cuatro módulos utilizando scripts Bash en el entorno Kali Linux.

El objetivo es aplicar conocimientos de administración de sistemas Linux, automatización de tareas, gestión de archivos y ejecución de comandos desde la terminal.

## . Objetivos

- Desarrollar scripts utilizando Bash.
- Automatizar tareas desde la terminal de Linux.
- Aplicar comandos de administración y gestión del sistema.
- Generar resultados y reportes mediante scripts.



## . Herramientas utilizadas

- Kali Linux.
- Bash Shell.
- Terminal de Linux.
- Git y GitHub.

## . Requisitos

- Sistema operativo Linux.
- Terminal Bash.
- Permisos de ejecución para los scripts cuando sean necesarios.

## . Ejecución

Para ejecutar los scripts desde la terminal:

```bash
chmod +x nombre_script.sh
./nombre_script.sh
```

Reemplazar `nombre_script.sh` por el nombre del archivo correspondiente.
